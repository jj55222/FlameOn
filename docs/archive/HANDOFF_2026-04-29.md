## 6. Operational gotchas (Windows-specific)

- **Always set `PYTHONIOENCODING=utf-8`** when invoking calibration. Otherwise the Unicode `─` on `evaluate.py` line 392 crashes cp1252 codec AFTER scoring completes.
- **Time budget too short.** `evaluate.py` has hardcoded `TIME_BUDGET_SECONDS = 1600`. Current per-case timing is ~45s, so 38 cases need ~30 min and overflows. **Use `run_calibration.py` wrapper** which monkey-patches the budget to 3600s without touching `evaluate.py`.
- **Brave key:** in `pipeline2_discovery/.env`. Paid plan, "monthly_remaining" header always returns `null` (= unlimited). Spend cap is `BRAVE_SPEND_LIMIT_USD` env var (default $5, override inline).
- **Per-case Brave cost:** ~$0.06 (11 queries × $0.005). 38-case calibration ≈ $2.10.
- **Module reload bug:** `evaluate.py` does `del sys.modules["research"]` per case, so the post-run `_api_call_counts` shows 0. The real counts are in `brave_quota.json`. Don't trust the "Efficiency Report" stdout block.


```
  python -u run_calibration.py --log \
  --hypothesis "weekly_drift_check_$(date +%Y%m%d)" \
```
