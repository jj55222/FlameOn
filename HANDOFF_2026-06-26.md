## The harness (in `pipeline4_scoring/`)
- **`evaluate_salience.py`** (immutable yardstick) — scores extracted moments vs a golden key: salience-weighted
  recall + grounding-as-precision (a quote is real iff it resolves in the source) + temporal/quote match. Discoveries
  (grounded-but-novel) vs hallucinations (ungrounded). `--selftest` passes.
- **Two-pass doc pipeline:** `doc_pass1.py` (extract beats from a full OCR'd report, swappable `--model`) →
  `pass1_union.py` (union N extractors' grounded candidates) → `pass2_judge.py` (a reasoning model rates/prunes;
  `--panel A B` = consensus merge). `beat_miner.py` mines audio-transcript beats (cue heuristic or LLM).
- **`score_run.py`** — mixed-key scorer (audio=temporal, doc=quote-match) for grading a run vs the frozen key.
- **`llm_backends.py`** — OpenRouter facade; now CAPTURES reasoning traces (`backend.last_reasoning` / `extract_think`).
